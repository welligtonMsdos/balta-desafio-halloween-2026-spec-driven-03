# Data Model: Link Shortener

## ShortLink

Represents a persistent short code and its redirect destination.

| Field | Type | Required | Rules |
|-------|------|----------|-------|
| `Id` | UUID | Yes | Persistence identity; generated by the service or database. |
| `Code` | string (4–20) | Yes | ASCII letters/digits only; canonical invariant uppercase; unique database index. Generated codes have exactly 7 characters. |
| `DestinationUrl` | string | Yes | Well-formed absolute HTTP or HTTPS URL; maximum 2048 characters. |
| `CreatedAtUtc` | UTC `DateTime` | Yes | Set by the service when accepted. |
| `ExpiresAtUtc` | nullable UTC `DateTime` | No | If present, must be strictly later than creation time. The link is expired when `now >= ExpiresAtUtc`. |
| `AccessCount` | `long` | Yes | Starts at zero, never decreases, and is incremented by one in a database-side atomic update only for an eligible redirect. |

### Relationships and indexes

- No user or creator relationship exists; account registration is out of scope.
- Add a unique index on canonical `Code`. All lookups normalize input using the same
  invariant-uppercase rule before querying.
- No separate `Access` row is required. `AccessCount` is the persisted aggregate of requests
  that receive a redirect response.
- Keep successful `LinkCreationAttempt` records for the rolling-window policy below; discard
  attempts older than 60 seconds. The persistence transaction coordinates rate reservation
  with link creation to avoid concurrent requests exceeding the limit.
- No management-key property is present in this feature. Future protected management must
  store only a hash of its key.

## LinkCreationAttempt

Represents a successful link creation for source-address rate limiting.

| Field | Type | Required | Rules |
|-------|------|----------|-------|
| `Id` | UUID | Yes | Persistence identity. |
| `SourceAddress` | string | Yes | Address resolved from the connection or a configured trusted proxy; retained only while it can affect the 60-second window. |
| `CreatedAtUtc` | UTC `DateTime` | Yes | Timestamp used to evaluate the rolling window. |

The source address and link insert are recorded as one atomic persistence operation after
validating the per-address limit. The application service defines the maximum of 10 in the
preceding 60 seconds; provider-specific transaction coordination remains in infrastructure.
Attempts older than 60 seconds are cleaned up during subsequent creation operations.

### State and transitions

- **Active**: `ExpiresAtUtc` is null or later than the current UTC instant.
- **Expired**: `ExpiresAtUtc` is at or before the current UTC instant. The record remains
  available to statistics; redirect attempts do not increment the count.
- **Creation**: Validate the destination, optional code, and future expiry; canonicalize code;
  check for existing code; persist with count zero. The unique index resolves races missed by
  the pre-check.
- **Redirect**: Atomically increment only if the code exists and is active. Return a redirect
  only when exactly one record was updated; otherwise distinguish unknown from expired for
  the response without changing the count.
- **Statistics**: Return the current count for any existing record, including expired links.
